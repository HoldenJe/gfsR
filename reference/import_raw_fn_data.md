# Import Generic FN DATA.ZIP

Provides a generic unzip function but with console prompts to add
missing FN011 fields.

## Usage

``` r
import_raw_fn_data(generic_datazip)
```

## Arguments

- generic_datazip:

## Value

list of FN Tables

## Examples

``` r
if (FALSE) { # \dontrun{
fn <- import_raw_fn_data("~/FNData/NS1/IA02_NS1/DATA.ZIP")
} # }
```
