# Append Species Names

function that appends species names and codes (SpcName) to a working
data frame.

## Usage

``` r
append.spc.names(fntable)
```

## Arguments

- fntable:

  a data table that has a column SPC indicating the species code (e.g.
  FN125)

## Value

returns a merged dataframe
