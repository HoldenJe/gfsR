# Makes a FN2 project directory name

Takes a year and a program type and forms a project directory code.
Generally only used within other functions.

## Usage

``` r
make.project(yr, program)
```

## Arguments

- yr:

  is a field season year (e.g. 2013)

- program:

  is a character vector specifying a program ('GL1')

## Value

returns a project directory code ('IA13_GL1')
