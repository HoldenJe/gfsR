# import_creel_series: Imports a series of DATA.ZIP files

import_creel_series: Imports a series of DATA.ZIP files

## Usage

``` r
import_creel_series(datazips, convert_dates = TRUE)
```

## Arguments

- datazips:

  File path to FN DATA.ZIP folder for a creel project

## Value

list of FN2 Tables

## Examples

``` r
if (FALSE) { # \dontrun{

} # }
```
