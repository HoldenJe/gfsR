# fl.rwt

fl.rwt

## Usage

``` r
fl.rwt(species, my125, logplot = FALSE)
```

## Arguments

- species:

  three digit species code (e.g. '081')

- my125:

  the location of the FN125 data (e.g. fndata\$FN125)

- logplot:

  optional argument to plot a log-log plot, default = FALSE

## Details

provides a quick diagnostic plot for looking for data errors
